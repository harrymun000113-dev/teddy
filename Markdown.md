Streamlit components require a thread context set up by its execution server. When executed standardly via python app.py, features like st.session_state or UI rendering fail to initialize, raising missing ScriptRunContext warnings.

How to fix:

Run the script from your terminal using the Streamlit runner:

Bash
streamlit run app.py
Common Scenarios & Fixes:

Running inside a standard Python script/tool: If you are importing Streamlit components inside a backend script or test suite rather than running a web app, remove the import streamlit or st.* calls from the non-UI context.

Running from VS Code / IDE: Check your launch configuration or run task to ensure it invokes streamlit run rather than the default python executable.

Running from a background thread: If you intentionally spawn threads within a Streamlit app and call st.* functions inside them, attach the context explicitly before making Streamlit calls:

Python
from streamlit.runtime.scriptrunner import add_script_run_ctx

thread = threading.Thread(target=your_function)
add_script_run_ctx(thread)
thread.start()
